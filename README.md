# istvanszasz99.dev

A modern, interactive personal portfolio website showcasing projects, skills, and professional experience. Built with cutting-edge web technologies for optimal performance and user experience.

## Features

- **Hero Section** - Eye-catching introduction with animated elements
- **About** - Professional background and introduction
- **Experience** - Work history and professional achievements
- **Projects** - Showcase of featured projects and portfolio work
- **Tech Skills** - Display of technical proficiencies with interactive marquee animation
- **Contact** - Get in touch section for collaboration opportunities
- **Custom Cursor** - Personalized interactive cursor experience
- **Responsive Design** - Fully responsive and mobile-optimized
- **Dark Mode Support** - Theme support with Tailwind CSS

## Tech Stack

- **Frontend Framework**: React with TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Animation**: Motion
- **Deployment**: Cloudflare Workers (wrangler)
- **Package Manager**: pnpm

## Installation

Run the following command to install dependencies:

```bash
npm i
```

or with pnpm:

```bash
pnpm install
```

## Development

Start the development server:

```bash
npm run dev
```

The application will be available at `http://localhost:5173` (or the port specified by Vite).

## Building

Build for production:

```bash
npm run build
```

## Deployment

This project is configured for Cloudflare Workers deployment using Wrangler. See `wrangler.toml` for configuration details.
